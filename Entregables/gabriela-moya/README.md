# Secure-by-Design Architecture Advisor

Aplicación web orientada a arquitectos de soluciones que permite realizar una evaluación temprana de seguridad sobre diseños cloud.

A partir de información sobre activos, datos, identidades, exposición y controles existentes, la herramienta genera:

- Amenazas basadas en STRIDE.
- Brechas relacionadas con Zero Trust.
- Requisitos de seguridad.
- Controles AWS recomendados.
- Resultado preliminar del gate de arquitectura.
