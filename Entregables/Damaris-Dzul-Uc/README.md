# Damaris Dzul Uc — Becas Hunucmá

> TP Final — Arquitectura de Computación en la Nube 2026, AWS Women in Cloud Buenos Aires.

---

## Resumen del proyecto

**Becas Hunucmá** — App web para digitalizar y filtrar automáticamente las solicitudes de becas universitarias del ayuntamiento de Hunucmá, Yucatán, México, dockerizada, con propuesta de infraestructura en AWS.

| | |
|---|---|
| **App** | Node.js + Express + PostgreSQL |
| **Docker** | `docker compose up` en `app/` |
| **DB** | PostgreSQL (relacional) |
