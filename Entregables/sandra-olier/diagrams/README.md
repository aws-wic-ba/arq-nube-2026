# Diagramas de arquitectura

Esta carpeta contiene los diagramas de la solución en formato draw.io y PNG.

Archivos:
- `arquitectura-local.drawio` / `arquitectura-local.png`: diseño de los contenedores y el flujo local con Docker.
- `arquitectura-aws.drawio` / `arquitectura-aws.png`: propuesta de infraestructura en AWS para desplegar la aplicación.

Ambos archivos `.drawio` pueden abrirse en [diagrams.net](https://app.diagrams.net/) para editar y exportar en otros formatos.

Consejos:
- Mantener los dos formatos en la entrega para que el evaluador pueda ver el diagrama editable y la imagen lista para mostrar.
- Usar iconos oficiales de AWS en el diagrama AWS para mejorar la claridad visual.
