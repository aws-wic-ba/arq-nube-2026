# Radar Tracker MVP

Aplicación web desarrollada en Python y Flask como trabajo práctico de Arquitectura Cloud 2026.

El proyecto presenta un prototipo de detección de oportunidades de mercado basado en una arquitectura serverless sobre AWS.

## Documentación

La documentación del proyecto se encuentra en la carpeta `docs/`, donde se incluyen:

- Descripción del proyecto.
- Arquitectura local.
- Arquitectura AWS.
- Evaluación según AWS Well-Architected Framework.
- Estimación de costos.
- Estrategia de Disaster Recovery.

##  Los íconos de servicios de AWS utilizados en este proyecto pertenecen a Amazon Web Services y se emplean únicamente con fines educativos e ilustrativos.
