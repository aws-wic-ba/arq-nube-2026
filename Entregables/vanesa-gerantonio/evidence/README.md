# Evidencias de OrganiCloud

Las siguientes capturas fueron obtenidas durante la ejecución local de OrganiCloud con Docker Compose y PostgreSQL.

## Validación realizada

- Construcción de la imagen Docker.
- Inicio del contenedor de la aplicación.
- Inicio y healthcheck de PostgreSQL.
- Acceso correcto desde `http://localhost:8000`.
- Visualización de la página principal.
- Visualización del organigrama dinámico.
- Consulta de una unidad organizativa.
- Publicación del proyecto en LinkedIn.
