# 01 — Descripción de OrganiCloud

## Problema real

Cada actualización de la estructura institucional obliga hoy a modificar por separado el organigrama en Visio y el manual de misiones y funciones en Word. Este trabajo manual consume tiempo y puede dejar documentos contradictorios o desactualizados.

## Idea y usuarios

OrganiCloud reúne ambas tareas en una sola aplicación. Está pensada para las personas responsables de organización y métodos, Recursos Humanos, autoridades, Auditoría y Cumplimiento.

## Funcionalidades verificables

1. Consultar un organigrama dinámico y navegar desde cada cuadro a su ficha.
2. Buscar unidades por nombre, tipo o misión.
3. Crear y editar unidades, dependencias, misión y funciones.
4. Registrar una nueva versión y el motivo de cada cambio.
5. Exportar una ficha o el manual completo a Word.
6. Verificar aplicación y base mediante `/health`.

La carga inicial respeta la estructura proporcionada. “Unidad de Prevención de Delitos Financieros” fue normalizada como **Unidad de Prevención**, manteniendo sus dependencias.
