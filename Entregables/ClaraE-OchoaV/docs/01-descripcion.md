# SecureReport

## Descripción

SecureReport es una aplicación web desarrollada en Python utilizando Flask que permite registrar y visualizar incidentes de seguridad informática.

La aplicación fue desarrollada como parte del Trabajo Práctico Final del curso Arquitectura de Computación en la Nube 2026.

## ¿Qué hace la aplicación?

La aplicación permite:

- Registrar incidentes de seguridad.
- Ingresar un título para el incidente.
- Escribir una descripción del incidente.
- Seleccionar el nivel de severidad (Alta, Media o Baja).
- Visualizar los incidentes registrados en una tabla.

## ¿Para quién está dirigida?

Esta aplicación está dirigida a:

- Analistas SOC.
- Equipos de Ciberseguridad.
- Personal de TI.
- Administradores de Infraestructura.

Su objetivo es facilitar el registro y seguimiento de incidentes de seguridad de forma sencilla y organizada.

## Tecnologías utilizadas

- Python 3
- Flask
- Docker
- Docker Compose
- HTML
- Bootstrap 5
