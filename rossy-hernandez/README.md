## Descripción del Proyecto
Prototipo interactivo y propuesta de arquitectura en AWS para la plataforma del Hospital Pediátrico Oncológico HopeCare.

## Resumen de la Arquitectura
* **Enfoque:** Serverless-First con microservicios desacoplados.
* **Seguridad:** Aislamiento total en dos dominios (Público/Donaciones y Clínico/PHI).
* **Servicios Clave:** AWS Lambda, Amazon API Gateway, AWS AppSync, Amazon Aurora PostgreSQL, AWS HealthImaging, Amazon DynamoDB, AWS WAF y Amazon QuickSight.
